Identification problem

1. Introduction

The identification gap is the difference between what a statistical model can recover from data and what actually generates the observations.

Formally, a parameter $\theta$ is identified if the mapping from $\theta$ to the distribution of observables $P(X; \theta)$ is injective: if $P(X; \theta_1) = P(X; \theta_2)$ implies $\theta_1 = \theta_2$. This fails when multiple parameter sets produce the same distribution and the model is under-identified. The data alone cannot tell them apart.

This gap is not a limitation of any particular method. It is a property of the data, the covariance matrix does not contain enough information to identify the structural model. Both PCA and OLS are reduced-form methods. They describe the data, not the mechanism that generated it. Neither can close the gap without additional information.

2. PCA

Consider two structural models with two agents and two latent factors $F_1, F_2$ (uncorrelated, equal variance $\sigma^2$)

$$\text{Model A:} \quad o_1 = a F_1, \quad o_2 = b F_2, \quad \operatorname{Var}(o_1) = a^2 \sigma^2, \quad \operatorname{Var}(o_2) = b^2 \sigma^2, \quad \operatorname{Cov}(o_1, o_2) = 0$$

$$\text{Model B:} \quad o_1 = a F_2, \quad o_2 = b F_1, \quad \operatorname{Var}(o_1) = a^2 \sigma^2, \quad \operatorname{Var}(o_2) = b^2 \sigma^2, \quad \operatorname{Cov}(o_1, o_2) = 0$$

Both models produce the same covariance matrix

$$\Sigma = \begin{pmatrix} a^2 \sigma^2 & 0 \\ 0 & b^2 \sigma^2 \end{pmatrix}$$

PCA on $\Sigma$ returns the same eigenvectors $(1,0)^\top$ and $(0,1)^\top$ in both models. The statistical components are identical.

It means that the PCA eigenvectors (the factors) are artifacts of the covariance matrix, not mechanisms. They may be mixtures of multiple structural components, or they may be statistical noise. The data cannot tell us which.

Now suppose a future quantity depends only on factor $F_1$

$$R = F_1 + \varepsilon$$

$$\text{Model A:} \quad o_1 = a F_1, \quad \text{so $R$ is correlated with $o_1$}.$$

$$\text{Model B:} \quad o_2 = b F_1, \quad \text{so $R$ is correlated with $o_2$}.$$

Regressing $R$ on $(o_1, o_2)$ gives completely different coefficients

Same covariance matrix. Same PCA eigenvectors. Different predictive relationships. This is the identification gap.

3. OLS

Consider the true mode:

$$y = \beta_1 x_1 + \beta_2 x_2 + \varepsilon$$

If $x_1$ and $x_2$ are perfectly collinear ($x_2 = 2 x_1$), then $\operatorname{rank}(X) = 1 < 2 = k$. The rank condition fails. OLS cannot identify $\beta_1$ and $\beta_2$ separately. Only the combination $1 = \beta_1 + 2\beta_2$ is identified. The following two models produce identical predictions:

$$\text{Model A:} \quad \beta_1 = 1, \; \beta_2 = 0$$

$$\text{Model B:} \quad \beta_1 = 0, \; \beta_2 = 0.5$$

In both cases, $\hat{y} = x_1$. The data cannot distinguish them. This is the same gap as in the PCA example, multiple parameter sets produce the same distribution of observations.
